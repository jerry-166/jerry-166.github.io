## 重点题详解

### 第 4 题：多道批处理 A/B 作业最短完成时间

**题意**：A、B 两个作业各含 "计算→I/O→计算" 三段，B 比 A 晚到 5ms，求完成全部任务的最小时间。

**思路**：核心是让 **CPU 计算与 I/O 操作尽量重叠**，不让 CPU 空闲。A 做 I/O 时 CPU 跑 B 的计算，B 做 I/O 时 CPU 跑 A 剩余计算。

**时间轴推导**（以经典参数为例）：



* A：计算 60ms → I/O 80ms → 计算 20ms

* B：计算 120ms → I/O 40ms → 计算 40ms（B 比 A 晚到 5ms）



| 时间段     | CPU               | I/O      |
| ------- | ----------------- | -------- |
| 0–60    | A 计算              | 空闲       |
| 60–140  | B 计算（B 5ms 到达后启动） | A I/O    |
| 140–180 | B 计算（继续）          | A I/O 结束 |
| 180–200 | A 计算（第二段）         | 空闲       |
| 180–220 | （B 同时做 I/O）       | B I/O    |
| 220–260 | B 计算（第二段）         | 空闲       |

**结论**：最短完成时间约 260ms，CPU 利用率 = 总计算时间 ÷ 总时间。关键原则是 "CPU 不空转、I/O 不排队"。

### 第 5 题：事务持久性与一致性的区分

**题意**：考 ACID 中 "持久性（Durability）" 的定义。

**易错点**：容易把一致性和持久性搞混。

**正确区分**：



* **一致性（Consistency）**：事务执行前后，数据库从一种一致状态转变为另一种一致状态，数据始终满足约束规则。

* **持久性（Durability）**：事务一旦提交，对数据的修改就是永久性的，即使数据库宕机、断电，重启后数据也不会丢失。靠 Redo Log（重做日志）实现。

**其他两个**：



* 原子性（Atomicity）：要么全部执行，要么全部不执行。

* 隔离性（Isolation）：并发事务之间互不干扰。

**结论**：选 "事务提交后修改永久保存、宕机不丢" 才是持久性；"从一致性到另一种一致性" 是一致性的定义。

### 第 7 题：装饰器模式与子类化增强

**题意**：场景描述为 "通过子类化 / 增强来扩展功能"，选项含装饰器、组合、适配器。

**各模式核心**：



* **装饰器模式**：动态地给对象添加额外职责，**不通过继承硬扩展**，通过对象包裹实现（如 Java IO 中 `BufferedInputStream` 包裹 `FileInputStream`）。

* **适配器模式**：把一个接口转换成客户端期望的另一个接口，解决接口不兼容。

* **组合模式**：处理 "整体 - 部分" 树形结构，统一对待单个对象和组合对象。

* **模板方法模式**：抽象类定义算法骨架，子类重写可变步骤（单继承、固定流程定制）。

**结论**：题干强调 "不用继承硬扩展、动态给对象加功能增强"→ 选装饰器模式。若强调 "子类继承重写固定流程步骤"→ 模板方法。本题选项无模板方法时，装饰器最贴合 "不用继承硬扩展" 的描述。

### 第 18 题：朴素递归斐波那契的时间 / 空间复杂度

**题意**：朴素递归写法 `return fib(n-1) + fib(n-2)` 的时间复杂度和空间复杂度。

**易错点**：容易误选时间 O (n)、空间 O (n)。

**推导**：



* 递推式：T (n) = T (n-1) + T (n-2) + O (1)，边界 T (0) = T (1) = O (1)

* 递归树是指数级展开，存在大量重复计算（fib (n-2) 被算了两次）

* 时间复杂度：**O(2ⁿ)**（≈ 1.618ⁿ，即黄金比例增长）

* 空间复杂度：**O(n)**（递归调用栈最深到 n 层，每层常数空间）

**优化对比**：



* 记忆化递归（加缓存）：时间 O (n)，空间 O (n)

* 迭代 DP：时间 O (n)，空间 O (1) 或 O (n)

**结论**：纯朴素递归时间复杂度是指数级 O (2ⁿ)，不是 O (n)。

### 第 19 题：栈 push/pop 后栈顶地址计算

**题意**：给定初始栈顶地址和操作序列（push、push、pop、pop、push），求最终栈顶地址。

**关键**：先看题目规定的**栈增长方向**：



* **向下增长**（x86 主流）：push 时 SP -= 单位大小，pop 时 SP += 单位大小

* **向上增长**：push 时 SP += 单位大小，pop 时 SP -= 单位大小

**举例**（向上增长，初始 SP = 1000，每次操作 ±1）：



1. push → 1001

2. push → 1002

3. pop → 1001

4. pop → 1000

5. push → 1001

**结论**：最终栈顶 = 1001。操作序列本质是 "压两次、弹两次、再压一次"，净效果等于只压了一次。题目没说增长方向时默认 x86 向下增长，按题目给定规则逐步推即可。

### 第 20 题：拉链法哈希表平均查找长度 ASL

**题意**：哈希函数 H (key) = key % 7，拉链法解决冲突，给定具体拉链结构，求平均查找长度。

**公式**：



* **查找成功 ASL** = 各元素查找时的比较次数之和 ÷ 元素总数

* **查找不成功 ASL** = 各哈希地址上找到空指针的比较次数之和 ÷ 哈希地址总数

**示例**（题目中拉链结构：0 号链挂 63，5 号链挂 5 和 40，其余 1/2/3/4/6 号各挂一个）：



* 0 号链：63（第 2 个）→ 比较 2 次

* 5 号链：5（第 1 个）→ 1 次，40（第 2 个）→ 2 次

* 1/2/3/4/6 号链：各 1 个元素 → 各 1 次

成功 ASL = (2 + 1 + 2 + 1×5) ÷ 7 = **11/7**

**结论**：拉链法中，同一哈希地址下第 k 个元素需要比较 k 次；无冲突时每个元素都只比较 1 次，ASL = 1。

### 编程题 1：翻转字符串里的每个单词

**题意**：给定一个以空格分隔的单词字符串（如 `"the sky is blue"`），翻转每个单词内部的字符顺序，但保留单词之间的空格和顺序。

**思路**：按空格 split 成单词数组，对每个单词做逆序，再用空格 join 回去。

**代码（Python）**：



```
\# 代码中的类名、方法名、参数名已经指定，请勿修改

\# 翻转字符串里的每个单词

\# @param words string字符串 一个个单词，以空格分隔，如"the sky is blue"

\# @return string字符串

class Solution:

&#x20;   def reverseString(self, words: str) -> str:

&#x20;       # 按空格分割成单词列表，每个单词\[::-1]逆序字符，再用空格拼接

&#x20;       temp = " ".join(\[word\[::-1] for word in words.split(" ")])

&#x20;       return temp
```

**复杂度**：时间 O (n)，空间 O (n)。

### 编程题 2：从 1\~n 选数和为 m 的所有组合

**题意**：输入 n 和 m，从 1 到 n 中选出若干不重复的数，使它们的和恰好等于 m，输出所有组合（每个组合内升序）。

**思路**：回溯法。枚举每个数选或不选，为避免重复组合，规定每次只能从当前数之后选（start = 上一个选的数 + 1）。用 visited 数组标记已选，sum (temp) == m 时记录。

**代码（Python）**：



```
import sys

\# 读取 n 和 m

for line in sys.stdin:

&#x20;   a = line.split()

&#x20;   n, m = int(a\[0]), int(a\[1])

ans = \[]          # 存储所有满足条件的组合

visited = \[False] \* (n + 1)  # 标记数字是否已被选

def solve(temp):

&#x20;   # 退出条件：当前组合之和等于 m

&#x20;   if sum(temp) == m:

&#x20;       ans.append(temp.copy())

&#x20;       return

&#x20;   # 下一个数只能从比上一个数大的开始选，保证组合内升序、不重复

&#x20;   start = temp\[-1] + 1 if len(temp) > 0 else 1

&#x20;   for i in range(start, n + 1):

&#x20;       if not visited\[i]:

&#x20;           # 剪枝：当前和 + i 超过 m 就不用再试更大的数

&#x20;           if sum(temp) + i <= m:

&#x20;               visited\[i] = True

&#x20;               temp.append(i)

&#x20;               solve(temp)          # 递归选下一个

&#x20;               visited\[i] = False   # 回溯：撤销选择

&#x20;               temp.pop()

&#x20;           else:

&#x20;               return  # 后面的数更大，直接 break

solve(\[])

\# 按要求格式输出每个组合

for a in ans:

&#x20;   for c in a:

&#x20;       print(c, sep=" ", end=" ")

&#x20;   print()
```

**复杂度**：时间 O (2^n)（最坏枚举所有子集），空间 O (n)（递归栈 + visited）。

### 编程题 3：0-1 背包求最小剩余空间

**题意**：给定背包容量 V 和 n 个物品的价值（本题物品重量等于价值），每个物品只能选一次，求背包装满后最小的剩余空间（即 V - 能装入的最大重量）。

**思路**：0-1 背包 DP。dp \[i]\[j] 表示前 i 个物品在容量 j 下能装入的最大重量。转移方程：dp \[i]\[j] = max (dp \[i-1]\[j], dp \[i-1]\[j-w \[i]] + w \[i])。最后答案 = V - dp \[n]\[V]。

**代码（Python）**：



```
import sys

V = list(map(int, input().split()))\[0]  # 背包容量

n = int(input().split()\[0])              # 物品数量

value = \[]

for i in range(n):

&#x20;   a = int(input().split()\[0])

&#x20;   value.append(a)  # 本题物品重量 = 价值

\# dp\[i]\[j]：前 i 个物品在容量 j 下能装入的最大重量

dp = \[\[0] \* (V + 1) for \_ in range(n + 1)]

for i in range(1, n + 1):

&#x20;   for j in range(1, V + 1):

&#x20;       # 不放第 i 个物品

&#x20;       t3 = dp\[i - 1]\[j]

&#x20;       # 放第 i 个物品（注意 value 数组下标从 0 开始，用 value\[i-1]）

&#x20;       if j - value\[i - 1] >= 0:

&#x20;           t2 = dp\[i - 1]\[j - value\[i - 1]] + value\[i - 1]

&#x20;       else:

&#x20;           t2 = 0

&#x20;       dp\[i]\[j] = max(t2, t3)

\# 最小剩余空间 = 总容量 - 最大装入重量

print(V - dp\[n]\[V])
```

**复杂度**：时间 O (n×V)，空间 O (n×V)（可优化为 O (V)）。
