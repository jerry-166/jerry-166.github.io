## 编程题：顺序装箱最少箱子数

### 题意

给定 n 个物品的重量数组，以及单个箱子的最大容量。按物品给定顺序依次装箱：若当前箱子装不下下一个物品则新开一个箱子，求总共需要的箱子数量。

### 思路

贪心模拟。遍历每个物品，维护当前箱子已装重量 `temp`：

- 加入当前物品后超出容量：新开一个箱子，当前物品放入新箱；
- 刚好等于容量：当前箱子封箱，已装重量重置为 0；
- 小于容量：继续累加。

遍历结束后，若还有未封箱的剩余物品，额外再加一个箱子。

### 代码（Java）

```java
import java.util.Scanner;

// 注意类名必须为 Main，不要有任何 package xxx 信息
public class Main {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int n = in.nextInt();
        int[] li = new int[n];
        int ans = 0;
        // 读入所有物品重量
        for (int i = 0; i < n; i++) {
            li[i] = in.nextInt();
        }
        int capa = in.nextInt();
        int temp = 0; // 当前箱子已装重量
        for (int i = 0; i < n; i++) {
            int curr = temp + li[i];
            if (curr > capa) {
                // 装不下，新开一个箱子，当前物品放入新箱
                ans += 1;
                temp = li[i];
            } else if (curr == capa) {
                // 刚好装满，封箱
                ans += 1;
                temp = 0;
            } else {
                // 装得下，继续往当前箱子放
                temp = curr;
            }
        }
        // 最后还有未封箱的物品，补一个箱子
        if (temp != 0) {
            ans += 1;
        }
        System.out.println(ans);
        in.close();
    }
}
```

### 复杂度分析

- 时间复杂度：O(n)，仅一次遍历数组。
- 空间复杂度：O(n)，用于存储物品重量数组；也可边读边算优化到 O(1)。

### 边界情况

- 所有物品刚好装满整数个箱子：末尾 `temp` 为 0，不会重复计数。
- 只有一个物品：正确输出 1。
- 代码隐含前提：单个物品重量不超过箱子容量；若存在超重物品需按题意另行处理。

## 编程题：工作流节点层级连线生成

### 题意

给定 n 个节点，每个节点包含节点名称和层级 `f`。按层级从小到大生成工作流连线：

- 流程起始为 `start`，结束为 `end`；
- 同一层只有 1 个节点：直接与上一层出口、下一层入口相连；
- 同一层有多个节点：先由 `fork_层级` 分叉到各节点，再由各节点汇入 `join_层级`。

### 思路

1. 用 `TreeMap<Integer, List<String>>` 按层级 `f` 分组，TreeMap 天然保证层级按 key 升序排列；
2. 读入时记录最小层级 `firstN` 和最大层级 `lastN`，用于连接 `start` 和 `end`；
3. 逐层遍历：
   - 该层多节点：上一层出口 → `fork_f` → 各节点 → `join_f`，本层出口记为 `join_f`；
   - 该层单节点：上一层出口直接连该节点，本层出口即该节点；
   - 第一层接 `start`，最后一层接 `end`。

### 代码（Java）

```java
import java.util.Scanner;
import java.util.*;

// 注意类名必须为 Main，不要有任何 package xxx 信息
public class Main {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int n = in.nextInt();
        // TreeMap 保证按层级 f 升序遍历，value 为该层全部节点
        Map<Integer, List<String>> mapp = new TreeMap<>();
        int lastN = 0;
        int firstN = 1000000;

        for (int i = 0; i < n; i++) {
            String node = in.next();
            int f = in.nextInt();
            lastN = Math.max(lastN, f);
            firstN = Math.min(firstN, f);
            mapp.putIfAbsent(f, new ArrayList<String>());
            mapp.get(f).add(node);
        }

        // 若题目要求同层节点按字典序输出，取消下面注释即可（待确认）
        // for (List<String> list : mapp.values()) {
        //     Collections.sort(list);
        // }

        String lastC = ""; // 上一层的出口节点
        for (Map.Entry<Integer, List<String>> entry : mapp.entrySet()) {
            List<String> li = entry.getValue();
            int key = entry.getKey();

            if (li.size() > 1) {
                // —— 同层多节点：fork 分叉、join 汇合 ——
                if (key == firstN) {
                    System.out.println("start->fork_" + key);
                } else {
                    System.out.println(lastC + "->fork_" + key);
                }
                for (String s : li) {
                    System.out.println("fork_" + key + "->" + s);
                }
                for (String s : li) {
                    System.out.println(s + "->join_" + key);
                }
                lastC = "join_" + key;
                if (key == lastN) {
                    System.out.println(lastC + "->end");
                }
            } else {
                // —— 同层单节点：直接串联 ——
                if (key == firstN) {
                    System.out.println("start->" + li.get(0));
                } else {
                    System.out.println(lastC + "->" + li.get(0));
                }
                lastC = li.get(0);
                if (key == lastN) {
                    System.out.println(lastC + "->end");
                }
            }
        }
        in.close();
    }
}
```

### 复杂度分析

- 时间复杂度：O(n log n)，TreeMap 按 key 维护有序；节点连线输出本身为 O(n)。
- 空间复杂度：O(n)，存储全部节点。

### 边界情况

- 只有 1 个节点（第一层同时是最后一层）：必须同时输出 `start->节点` 和 `节点->end`，这正是初版代码漏掉的情况，详见考后深挖。
- 第一层 / 最后一层为多节点分叉：`start` 接 `fork`、`join` 接 `end`。
- 同层节点的输出顺序是否要求字典序：题目记录未明确，待确认；若要求则对每层 List 排序即可。

## 考后深挖：工作流代码边界 Bug 修复

### 问题现象

初版代码样例只通过了 93%，问题出在**单节点边界场景的逻辑缺失**：当输入只有 1 个节点（第一层同时也是最后一层，且该层仅 1 个节点）时，只会输出 `start->节点名`，不会输出 `节点名->end`，工作流缺少结束边。

### 根本原因

初版在单节点且为第一层的分支中，输出完 `start->节点` 后直接 `continue`，跳过了后续「是否为最后一层」的判断：

```java
if (key == firstN) {
    System.out.println("start->" + li.get(0));
    lastC = li.get(0);
    continue;   // 第一层同时是最后一层时，这里直接跳过了 ->end 的输出
}
```

当第一层同时也是最后一层（n = 1）时，结束边永远不会被打印。

### 修复方式

1. 单节点第一层分支中补上最后一层判断，第一层同时是最后一层时输出 `节点->end`；
2. 顺带删除多节点第一层分支里冗余的 `lastC = li.get(0)`，该赋值随后就会被 `join_key` 覆盖；
3. 把多节点分支中「第一层」与「非第一层」的公共逻辑合并，减少重复代码。

### 验证用例

输入：

```text
1
a 1
```

修复后输出：

```text
start->a
a->end
```

修复后原有多节点用例的逻辑完全兼容，不受影响。

### 经验总结

- 分层、分段构建图/流程的题，**首尾重合的最小输入（只有一个元素）是必测边界**；
- 用 `continue` 提前结束分支时，要检查是否跳过了本该在分支尾部统一执行的收尾逻辑；
- 提交前应对每一种「层节点数 × 是否首层 × 是否末层」的组合至少构造一个用例。
