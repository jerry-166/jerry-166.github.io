## 重点题详解

### 第 1 题：归并排序复杂度

针对长度为 N 的数组做标准二路归并排序：

- 递归划分层数为 O(log N)。
- 每一层所有子区间的元素总数仍为 N，该层合并总工作量为 O(N)。
- 因此最好、平均和最坏时间复杂度均为：

\[
O(N\log N)
\]

- 合并阶段需要临时数组保存合并结果，辅助空间为 O(N)。
- 递归栈空间为 O(log N)，但被临时数组的 O(N) 覆盖，所以总空间复杂度为：

\[
O(N)
\]

注意区分：如果只是执行一次「合并两个有序子数组」的 merge 操作，输入元素总数为 N，则该操作时间复杂度是 O(N)；完整归并排序才是 O(N log N)。

### 第 2 题：递推式复杂度

递推式：

\[
T(N)=3T(N/2)+N
\]

使用主定理：

\[
a=3,\quad b=2,\quad f(N)=N
\]

关键指数为：

\[
\log_b a=\log_2 3\approx 1.585
\]

比较 f(N) 与 N<sup>log<sub>2</sub>3</sup>：

\[
N=O(N^{\log_2 3-\varepsilon})
\]

满足主定理第一种情况，因此：

\[
\boxed{T(N)=\Theta(N^{\log_2 3})\approx \Theta(N^{1.585})}
\]

递归树深度确实是 log<sub>2</sub>N，但每层有 3 倍数量的子问题，不能只根据递归深度判断为 O(log N)。

### 第 3 题：大小端字节序

发送端按大端序发送一个 32 位数，例如：

\[
0x12345678
\]

大端序从最高有效字节开始发送，字节流为：

```text
12 34 56 78
```

接收端按小端序组装 32 位整数时，会把第一个字节当作最低有效字节，因此解释结果为：

\[
0x78563412
\]

结论：

- 四个字节本身的传输顺序没有变化。
- 变化的是接收端对这四个字节的数值解释方式。
- 不做字节序转换时，结果错误；应选选项 3「错误」。
- 跨平台网络收发通常使用 `htonl`、`ntohl` 等函数或显式按字节拼装。

## 编程题：有向图可达性判断

### 题意

给定使用邻接表表示的有向图、起点 `start` 和终点 `end`，判断从 `start` 是否可以到达 `end`。图中可能存在环，节点 id 合法，图可以为空。

邻接表格式约定为：

```text
graph: Dict[int, List[int]]
```

其中 key 是节点 id，value 是该节点指向的邻居列表。

### 思路

推荐使用 BFS：

1. 使用 `visited` 集合记录已经入队的节点。
2. 从 `start` 开始逐层遍历邻居。
3. 遇到 `end` 立即返回 `True`。
4. 环上的节点因为已经在 `visited` 中，不会重复入队，因此不会死循环。
5. 队列为空仍未遇到 `end`，返回 `False`。

边界情况：

- `start == end` 时直接返回 `True`。
- 空图中只有 `start == end` 可达。
- 某个节点没有出边时，邻接表中可能没有该 key，使用 `graph.get(cur, [])` 避免 `KeyError`。
- `end` 没有作为 key 出现不代表不可达，它仍可能作为其他节点的邻居被访问到。

### 代码（Python，可直接运行）

```python
from collections import deque
from typing import Dict, List


def is_reachable(graph: Dict[int, List[int]], start: int, end: int) -> bool:
    # 同一个节点默认可达自身
    if start == end:
        return True

    visited = {start}
    queue = deque([start])

    while queue:
        current = queue.popleft()

        # 节点不在邻接表中时，认为它没有出边
        for neighbor in graph.get(current, []):
            if neighbor == end:
                return True

            # visited 防止有环图中重复入队、死循环
            if neighbor not in visited:
                visited.add(neighbor)
                queue.append(neighbor)

    return False


# 带环图：0 -> 1，1 -> 2，2 -> 1
graph = {
    0: [1],
    1: [2],
    2: [1],
}

assert is_reachable(graph, 0, 2) is True
assert is_reachable(graph, 2, 0) is False
assert is_reachable(graph, 1, 1) is True

# 空图
assert is_reachable({}, 5, 5) is True
assert is_reachable({}, 1, 2) is False

print("all tests passed")
```

### 复杂度

设图中顶点数为 V、边数为 E：

- 时间复杂度：O(V + E)，每个顶点最多入队一次，每条出边最多检查一次。
- 空间复杂度：O(V)，访问集合和队列在最坏情况下保存所有顶点。

## 编程题：拆分整数求按位与最大值

### 题意

给定非负整数 n，将 n 拆成 x 和 n-x，其中 0 ≤ x ≤ n，求：

\[
v_x=x\ \&\ (n-x)
\]

的最大值。

### 思路

令：

\[
y=n-x,\quad a=x\&y,\quad b=x\oplus y
\]

加法和位运算满足：

\[
x+y=(x\oplus y)+2(x\&y)
\]

因为 x+y=n，所以：

\[
n=b+2a
\]

同时，同一个二进制位不可能既满足「两个数都为 1」又满足「两个数不同」，因此：

\[
a\&b=0
\]

代入 b=n-2a，问题转化为寻找最大的 a，使：

\[
2a\le n,\qquad a\&(n-2a)=0
\]

不能直接把答案写成 n//2。例如 n=11 时，n//2=5，但：

```text
x=5, y=6
5 & 6 = 4
```

实际最大值为 4，对应 x=7、y=4。

使用按位动态规划，从低位到高位同时决定 a 和 b 的比特位：

- b=n-2a，因此在第 i 位中，2a 的当前位等于 a 的第 i-1 位。
- 状态保存当前进位 `carry` 和 a 的上一位 `previous_a_bit`。
- 同一状态只保留数值最大的低位前缀。
- a 不能超过 n//2，所以 a 的最高位不能达到 n 的最高位。

### 代码（Python，可直接运行）

```python
from typing import Dict, Tuple


def max_and_after_split(n: int) -> int:
    """返回 max(x & (n - x))，其中 0 <= x <= n。"""
    if n < 0:
        raise ValueError("n must be non-negative")

    bits = n.bit_length()

    # 状态：(当前加法进位, a 的上一个二进制位)
    # 值：该状态下已经确定的、最大的 a 的低位部分
    dp: Dict[Tuple[int, int], int] = {(0, 0): 0}

    for i in range(bits + 1):
        target_bit = (n >> i) & 1
        next_dp: Dict[Tuple[int, int], int] = {}

        # a <= floor(n / 2)，a 不能设置到 n 的最高位
        allow_a_one = i <= bits - 2

        for (carry, previous_a_bit), value in dp.items():
            a_bit_choices = (0, 1) if allow_a_one else (0,)

            for a_bit in a_bit_choices:
                # a_bit & b_bit 必须为 0：a_bit 为 1 时，b_bit 只能为 0
                b_bit_choices = (0,) if a_bit == 1 else (0, 1)

                for b_bit in b_bit_choices:
                    # 第 i 位相加：2a 的该位是 a 的第 i-1 位
                    total = previous_a_bit + b_bit + carry

                    if (total & 1) != target_bit:
                        continue

                    next_state = (total >> 1, a_bit)
                    candidate = value | (a_bit << i)

                    # 同一状态只保留最大的低位前缀
                    if candidate > next_dp.get(next_state, -1):
                        next_dp[next_state] = candidate

        dp = next_dp

    # 最高位处理完后不能还有进位
    return dp.get((0, 0), 0)


def best_split(n: int) -> Tuple[int, int, int]:
    """返回最大按位与值以及对应的 x、y。"""
    maximum_and = max_and_after_split(n)
    b = n - 2 * maximum_and

    # a & b = 0，将所有异或位分配给 x，可构造出一组合法解
    x = maximum_and | b
    y = maximum_and
    return maximum_and, x, y


for n in [0, 1, 2, 5, 7, 11, 12]:
    maximum_and, x, y = best_split(n)
    assert x + y == n
    assert (x & y) == maximum_and
    print(f"n={n:2d}, x={x:2d}, y={y:2d}, x&y={maximum_and:2d}")
```

输出：

```text
n= 0, x= 0, y= 0, x&y= 0
n= 1, x= 1, y= 0, x&y= 0
n= 2, x= 1, y= 1, x&y= 1
n= 5, x= 3, y= 2, x&y= 2
n= 7, x= 7, y= 0, x&y= 0
n=11, x= 7, y= 4, x&y= 4
n=12, x= 6, y= 6, x&y= 6
```

### 复杂度

- 时间复杂度：O(log n)，只处理 n 的二进制位数，状态数为常数。
- 空间复杂度：O(1)，动态规划表最多保存常数个状态。

## 编程题：反转链表 II

### 题意

给定单链表头节点和区间位置 `left`、`right`，位置从 1 开始计数，只反转从 `left` 到 `right` 的节点，其余节点保持不变。

例如：

```text
1 -> 2 -> 3 -> 4 -> 5，left=2，right=4
结果：
1 -> 4 -> 3 -> 2 -> 5
```

### 思路

使用虚拟头节点和头插法：

1. 创建 `dummy` 节点并让 `dummy.next = head`，统一处理 `left=1` 的情况。
2. 移动 `pre` 到第 `left` 个节点的前驱位置。
3. 令 `cur = pre.next`，`cur` 始终指向待反转区间的原始第一个节点。
4. 重复 `right-left` 次，把 `cur.next` 移动到 `pre` 后面。
5. 最后返回 `dummy.next`。

头插时的指针顺序：

```text
nxt = cur.next
cur.next = nxt.next
nxt.next = pre.next
pre.next = nxt
```

### 代码（Python，可直接运行）

```python
from typing import List, Optional


class ListNode:
    def __init__(self, val: int = 0, next: Optional["ListNode"] = None):
        self.val = val
        self.next = next


class Solution:
    def reverseBetween(
        self,
        head: Optional[ListNode],
        left: int,
        right: int,
    ) -> Optional[ListNode]:
        if head is None or left == right:
            return head

        # 虚拟头节点，处理从链表头部开始反转的情况
        dummy = ListNode(-1, head)
        pre = dummy

        # pre 移动到 left 位置的前一个节点
        for _ in range(left - 1):
            pre = pre.next  # 题目保证位置合法，因此此处不会为 None

        cur = pre.next

        # 区间长度为 right-left+1，第一个节点保持为 cur，
        # 后续 right-left 个节点依次头插到 pre 后面
        for _ in range(right - left):
            nxt = cur.next

            cur.next = nxt.next
            nxt.next = pre.next
            pre.next = nxt

        return dummy.next


def build_list(values: List[int]) -> Optional[ListNode]:
    dummy = ListNode()
    current = dummy
    for value in values:
        current.next = ListNode(value)
        current = current.next
    return dummy.next


def to_list(head: Optional[ListNode]) -> List[int]:
    result = []
    while head is not None:
        result.append(head.val)
        head = head.next
    return result


head = build_list([1, 2, 3, 4, 5])
reversed_head = Solution().reverseBetween(head, left=2, right=4)
assert to_list(reversed_head) == [1, 4, 3, 2, 5]

print(to_list(reversed_head))
```

### 复杂度

- 时间复杂度：O(n)，定位前驱和头插操作合计最多扫描链表常数次。
- 空间复杂度：O(1)，只使用固定数量的指针。

### 易错点

- 不使用虚拟头节点时，`left=1` 会改变链表头节点，原写法容易漏处理。
- 不能提前把区间第一个节点的 `next` 置为 `None`，否则会直接丢失后续链表。
- 头插法不是跳过区间第一个节点，而是让它作为 `cur` 固定在原地，把后续节点逐个插到它前面。
